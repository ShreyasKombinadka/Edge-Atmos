## **Edge Atmos**

A local weather station built with no HAL and all custom drivers and libraries built from bare-metal register level coding.

## Overview
- Built on STM32 board with no HAL.
- All the driver and libraries are custom built.

## Libraries built
1. I2C driver
2. LCD1602 driver
3. ASCII conversion library
4. AHT10 Temperature and humidity sensor driver
5. BMP280 Pressure sensor driver
6. GPIO driver
7. SPI driver
8. W25Q32 Flash memory driver
9. ST7789LCD TFT display driver
10. Font bitmap file
